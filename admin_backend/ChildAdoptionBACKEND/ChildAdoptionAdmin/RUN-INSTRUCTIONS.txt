CHILD ADOPTION ADMIN API - RUN INSTRUCTIONS

1. Copy the complete folder ChildAdoptionAdmin to your workspace.
2. Open MySQL Workbench.
3. Open and execute: database/database.sql
4. Open: api/ChildAdoptionAdmin.Api/appsettings.json
5. Replace the MySQL Password value with your own MySQL root password.
6. Open PowerShell in: api/ChildAdoptionAdmin.Api
7. Run:
   dotnet restore
   dotnet build
   dotnet run
8. Open:
   http://localhost:5080/swagger

LOGIN
POST http://localhost:5080/api/auth/login
Body:
{
  "email": "admin@cdac.org",
  "password": "Admin@123"
}

For protected endpoints, copy the returned token, click Swagger Authorize,
and paste only the token.
